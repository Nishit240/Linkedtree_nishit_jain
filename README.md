## 📌 Features

✨ Minimal & Modern Dark UI  
📱 Fully Responsive (Mobile First Design)  
🎨 Smooth Animations & Hover Effects  
🔽 Expandable Portfolio Section  
📂 Project Showcase with Preview  
🔗 Social Media Quick Links  
💬 Contact Modal Popup  
🎯 Custom Styled Buttons (Neumorphism + Shadow Effect)
